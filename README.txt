SOURCE WEBSITE — EASY GITHUB UPLOAD

1. Extract this ZIP file on your computer.
2. Open the extracted folder.
3. Upload these four items directly into your GitHub repository:
   - index.html
   - styles.css
   - script.js
   - source-logo.jpeg
4. Do not upload the ZIP file itself.
5. In GitHub go to Settings > Pages.
6. Select Deploy from a branch > main > /root and save.
7. Wait 2–5 minutes, then open:
   https://sourcepropertyinvest-lang.github.io/source/

IMPORTANT BEFORE SHARING THE WEBSITE:
- Open index.html in Notepad.
- Replace 00000 000000 with your telephone number.
- Replace hello@yourdomain.co.uk with your real email address.
